01 / 08 hackathon NASA Space Apps, Nov 2026

MARS//404

Open live appSource

On Mars there is no GPS and no second chance. I led six people for 48 hours to answer one question: how far can I walk and still make it back?

TypeScript / WebGL / HiRISE DEMHow it is built +
  • Forearm-tablet planner on real NASA HiRISE terrain, 1 m per pixel.
  • Oxygen, energy and time are one budget, spent twice: out and back. Slopes and soft sand make the way back slower.
  • Gale crater, two science targets, Build route: “Return in 28 min, GO”. Drop O₂ by 40% and the point of no return appears.
  • Radio beacons instead of GPS.

02 / 08 private Oct 2026

freeforge

Ask for access

Night shift for a repo. Free LLM tiers write small tasks while I sleep, a judge with no opinions decides what stays, and I merge in the morning. Or I don’t.

TypeScript / opencode / FreeLLMAPIHow it is built +
  • One function or one component per task, files named up front.
  • The judge is your own tests, type checker, linter and build, plus rules the agent cannot argue with: no protected files, no diffs outside scope, no fewer tests than yesterday.
  • A second model reads the diff and rejects drive-by edits. Rejections go back to the agent with the reason.
  • Every read, edit and gate decision is an event. You watch it live as an isometric colony. This site borrows that colony.

03 / 08 private v4.0.1, with my brother

Step Memory

Ask for the APK

An Android app that remembers every step you take and paints it over a map. The fog lifts only where you have actually been, and grows back a year later.

Kotlin / Jetpack Compose / MapLibre / SQLiteHow it is built +
  • Tracking lives in its own tiny :tracker process. GPS sleeps when you stand still. Tracks snap to streets through Valhalla.
  • Day player: replays any day to any year, cars drive along the road instead of teleporting.
  • 20 medal series × 4 metals, 12 secret ones, a road to Paris, a night raid, a ghost.
  • 14 map styles with no API keys. Graphite metal and one red accent, #FF2A2A. Yes, the same red.

05 / 08 live v1.0.0, in production

SkillForge

Open the siteTelegram bot

You drop in a CV and in a few seconds you know what is weak, how many points each fix is worth, and which DOU and Djinni vacancies actually match.

Go / React / Expo / OpenAPI / CloudflareHow it is built +
  • Scores a CV on six criteria, then rewrites it for one vacancy using only facts already in it. Works without an account.
  • The backend started in Django. On a 1 GB server it went into swap, so it was rewritten in Go: 12 MB idle, 35 MB at peak with 100 users.
  • Web on Cloudflare Pages, an Android app and a Telegram bot, all on one API contract.

08 / 08 private launching, Nov 2026

FITGYM

Ask for a walkthrough

Booking for fitness clubs. Someone taps a link in the club’s Instagram, picks a class and books it. The admin sees it live and confirms in one tap.

Django 5.2 / DRF / Celery / React 19 / Three.js / SSEHow it is built +
  • Two people can never take the last spot: parallel confirms are a test, test_INV_04_parallel_confirms_never_overbook.
  • A double tap or a dropped connection does not create a second booking. Every booking rule is an invariant with a test named after it, and CI checks the list.
  • One codebase, many clubs. The club comes from the domain, an unknown host gets 404. The schedule is a 3D scene of glass blocks.
  • AI agents wrote the code: Claude Code led, Codex wrote parts of the specs and reviewed late PRs. The architecture, specs and invariants are mine.
