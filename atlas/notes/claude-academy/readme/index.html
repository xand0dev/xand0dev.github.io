Що є у випуску

Каталог зібрано зі сторінок Academy та програм курсів. Для 430 уроків опрацьовано доступний текст. Для восьми уроків, де викладений матеріал у доступному поданні не відображався, є бібліографічні дані, тема за програмою й оригінальна прикладна вправа. Відео та інтерактиви без доступного тексту в цій кількості не вважаються опрацьованими. Конспекти не підтверджують практичного виконання демо чи проходження навчальної перевірки. Тривалість наведено так, як її показує каталог і сторінки уроків. Сума тривалостей уроків може відрізнятися від оцінки курсу.

Кожен із 438 уроків має запис у Markdown та в каталозі. Тематичні повтори в треках API, Bedrock та Vertex об’єднані для retrieval у 316 канонічних записів та 122 відсилання зі своїми URL. Платформні розбіжності між однойменними уроками перевіряй за відповідним першоджерелом. Офіційні матеріали доступні за посиланнями. База містить власний стислий переказ і практичні рекомендації. Бейджі, PDF і verification URLs вносяться після фактичного підтвердження. Поля особистого прогресу початково мають статус unverified.

Імпорт у RAG

  1. Завантаж index.jsonl як UTF-8 JSON Lines. Одна строка — одна одиниця пошуку. Індексуй title, text, alias_titles і tags. Збережи kind, coverage та course_ids для фільтрів.
  2. Зовнішній ключ — doc_id + version. У проєктній БД додай tenant та ACL окремим фактором. Для оновлення same-ID запису порівнюй content_sha256 і source metadata. При змінах публікуй нову версію, фіксуй supersedes і лишай попередню для аудиту. Retrieval читає активну версію. Перший випуск не має попередніх версій.
  3. Канонічний ID уроку базується на маршруті джерела. aliases однозначно вказують на такий ID. Пошук точних термінів та векторів об’єднуй за канонічним ID. Додаткові збіги хешів і значень використовуй як кандидати на ручне об’єднання.
  4. Встанови зв’язок із sources/registry.json через source_ids. Під час відповіді вкажи source_urls, версію запису і тип матеріалу. attribution розрізняє матеріал Academy та власне застосування. Записи outline_only підтримують навігацію й вправи. Для нормативного твердження обирай public_text або актуальну специфікацію.
  5. Для відповідей по всьому курсу з’єднуй section і path через catalog.json. Для нових випусків порівнюй sources/course-checkpoints.json, число уроків і зміни coverage. Зберігай старі випуски до завершення аудиту.

Власні проєктні документи описують пропоновану реалізацію. Пакет не містить розгорнутого Orchestrator, підключеної векторної БД або результатів пілоту.
