Model Context Protocol: Advanced topics

11 уроків · 90 хв за каталогом · 1 офіційних quizzes · бейдж доступний Версія 1.0.0 · перевірено 2026-11-22 · Сторінка курсу

Позначки «Anthropic» переказують відкритий матеріал. «Застосування» та «Перевірка» є власними інженерними рекомендаціями.

Core MCP features

1. Sampling

9 хв · 2026-11-22 · Першоджерело

  • Anthropic · Sampling у викладеній версії дає серверу можливість просити клієнт про модельну генерацію.
  • Застосування · Зафіксуй як історичну можливість і перевір версію протоколу перед підключенням. Для MVP LLM викликає Orchestrator.
  • Перевірка · Не припускай підтримки чи дозволу на передачу документів клієнту.

2. Sampling walkthrough

15 хв · 2026-11-22 · Першоджерело Доступний лише видимий план або заголовок. Вправу чи відео окремо не підтверджено.

  • Тема за програмою · Програма позначає цей урок як практику sampling.
  • Застосування · В окремій сумісній тестовій сесії перевір відмову клієнта та обмеження моделі.
  • Перевірка · Опис відеодемонстрації не підтверджено. Поведінка залежить від версії й capability.

3. Log and progress notifications

7 хв · 2026-11-22 · Першоджерело

  • Anthropic · Сервер може повідомляти про перебіг і журнали виконання, доки триває запит.
  • Застосування · Зв’язуй події з operation ID, зберігай останній checkpoint, редагуй приватні поля.
  • Перевірка · Подія progress не підтверджує commit. Рішення про успіх приймай за станом операції.

4. Notifications walkthrough

15 хв · 2026-11-22 · Першоджерело Доступний лише видимий план або заголовок. Вправу чи відео окремо не підтверджено.

  • Тема за програмою · Програма позначає цей урок як практику сповіщень.
  • Застосування · Перевір, що UI відображає частковий прогрес, а фінальний результат має окремий статус.
  • Перевірка · Відео не підтверджено. Дублі й перестановка подій можливі на рівні твоєї черги.

5. Roots

2 хв · 2026-11-22 · Першоджерело

  • Anthropic · Roots у викладеній версії повідомляють серверу про робочі місця клієнта.
  • Застосування · Розглядай roots як підказку сумісності. Для доступу до файлів використовуй обмежений sandbox.
  • Перевірка · Root URI сам по собі не обмежує ОС. Перевір актуальну ревізію протоколу.

6. Roots walkthrough

15 хв · 2026-11-22 · Першоджерело Доступний лише видимий план або заголовок. Вправу чи відео окремо не підтверджено.

  • Тема за програмою · Програма позначає цей урок як практику roots.
  • Застосування · Змоделюй workspace із двома каталогами й перевір, що sandbox блокує читання за дозволеним піддеревом.
  • Перевірка · Деталі демонстрації не підтверджено. Файловий allowlist перевіряє канонічні шляхи.

Transports and communication

7. JSON message types

2 хв · 2026-11-22 · Першоджерело

  • Anthropic · Протокол використовує JSON-RPC з повідомленнями запиту, відповіді та одностороннього сповіщення.
  • Застосування · Зв’язуй response з request ID і обробляй timeout окремо для кожного виклику.
  • Перевірка · На notification не чекають response. Невідомий ID журналюй як помилку протоколу.

8. The STDIO transport

2 хв · 2026-11-22 · Першоджерело

  • Anthropic · STDIO передає повідомлення між клієнтом і локальним процесом через стандартні потоки.
  • Застосування · Окремий непривілейований процес і передбачуваний життєвий цикл. Логи в stderr.
  • Перевірка · Діагностика у stdout може пошкодити протокольний потік.

9. The StreamableHTTP transport

2 хв · 2026-11-22 · Першоджерело

  • Anthropic · Streamable HTTP забезпечує віддалений транспорт із відповідями, що можуть стримитися залежно від сценарію і ревізії.
  • Застосування · Для remote deployment вкажи supported versions, auth і bounded timeouts.
  • Перевірка · Непідтримуваний transport або origin має завершитись контрольованою відмовою.

10. StreamableHTTP in depth

2 хв · 2026-11-22 · Першоджерело

  • Anthropic · Урок розбирає маршрути повідомлень і SSE в тогочасній моделі Streamable HTTP.
  • Застосування · Для зафіксованої версії зроби contract tests POST, streaming, disconnect та повернення помилки.
  • Перевірка · Не перенось приклади сеансів у нову ревізію без звірки changelog.

11. State and the StreamableHTTP transport

2 хв · 2026-11-22 · Першоджерело

  • Anthropic · Урок пояснює вибір між stateful і stateless поведінкою SDK/транспорту.
  • Застосування · Стан workflow тримай у PostgreSQL. Адаптер MCP лише виконує інтеграцію.
  • Перевірка · Перезапуск конектора не повинен втрачати approved operation або спонукати повторний запис.
