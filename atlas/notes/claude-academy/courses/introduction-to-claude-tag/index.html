Introduction to Claude Tag

Позначки «Anthropic» переказують відкритий матеріал. «Застосування» та «Перевірка» є власними інженерними рекомендаціями.

  • Застосування · Прив’яжи один role tag до release status.

2. Claude in a DM

  • Застосування · Чернетку опублікуй вручну після відбору фактів.
  • Перевірка · Сирий DM не стає shared memory.

  • Перевірка · Чутливі дані клієнта лишаються поза повідомленням.

4. Claude in a private channel

  • Застосування · Перевір членство й destination перед будь-якою дією.
  • Перевірка · Не повторюй приватні висновки в загальному каналі.

5. Pick the right place for the work

  • Перевірка · Маршрут підтверди, якщо зміна аудиторії суттєва.
